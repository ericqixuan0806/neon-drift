## 验收目标

约定的核心玩家动作矩阵 100% 有可达路径，并由确定性回归覆盖；鼠标/触控、键盘和辅助 DOM 不重复触发或抢夺输入；购买/继续/重试不绕过已有规则；已有和恢复存档不丢失。游戏仍是遵守现有视觉规范、可直接打开的单文件 HTML。自动测试结果不代表浏览器、真实设备、视觉、读屏器或难度验收。

## M0 — 锁定旅程契约（已完成）

- 动作矩阵：菜单（开始、每日、外观、商店、关卡、任务、统计、设置、难度）；商店（前后页、11 个升级和 4 个技能购买）；关卡（前后页、返回）；游戏（左右移动、4 个已解锁技能、暂停）；暂停（继续、退出）；胜利（继续、退出）；结束（重试、菜单）；设置（各项切换、导出）。
- 确认源码/测试现状：单 HTML，23/23 自动测试通过；已加载 UI 规范，remote 是 `ericqixuan0806/neon-drift` 的公开 `main`。
- M0 验收：现有基线全绿；存档 schema 和当前价格/奖励/解锁规则已记录为不变约束。

## M1 — 共享动作与输入归属（已完成）

- 为购买、商店/关卡分页、首领胜利继续、技能激活和菜单转场提供小型共享动作，保持游戏规则常量。
- 指针拖动记录 owner `pointerId`；只有所有者移动、结束或取消才能改变/清除其状态。`lostpointercapture` 和 blur/hidden 也正确释放。
- 有转向 owner 时第二指仍可点已解锁技能或暂停；它不能取得拖动所有权。
- 当焦点在原生按钮/链接/表单控件时，游戏全局快捷键不处理该键；允许原生 Enter/Space click 行为；游戏输入仍在 Canvas/页面非控件区域响应。
- 实施：触控拖动现在追踪 owner `pointerId`；只处理 owner 的 move/up/cancel/lostpointercapture，第二指不能抢占方向，但可点技能/暂停。全局键盘忽略已由原生控件处理的键和按键重复，避免 Enter/Space 双触发及长按切换状态。
- 最终验收（在 M4 跨阶段矩阵中）：`node --test tests/save-state.test.cjs` 29/29 通过，覆盖非 owner 结束/取消不清除拖动、第二指技能点击保持方向、owner 取消清理、按钮 Enter/Space 与全局 handler 隔离、重复暂停键忽略。

## M2 — 主要操作入口一致（已完成）

- 辅助 DOM 操作区覆盖缺失的购买升级/技能、商店翻页、关卡翻页、Boss 胜利继续以及已购买的技能触发。
- 按当前状态、页、价格、所有权、冷却更新可用状态和可读标签；Canvas 和 DOM 调用相同动作。
- 实施：Canvas 和 DOM 共用升级/技能购买、商店/关卡分页、技能触发和 Boss 后继续动作；隐藏面板加入当前价/等级/效果/拥有/冷却语义，并为长列表提供样式规范下的可滚动焦点区。Boss Continue 随 600ms 展示延迟正确启用；技能冷却完成时刷新其按钮状态。
- 验收：29/29 全量自动检查通过，含成功购买保存重载、余额不足、已拥有/冷却阻止重复、Boss 继续及死亡重试。

## M3 — 学习与结果反馈（已完成）

- 菜单/暂停提供一屏简明帮助：实际可用的转向输入、技能键、危险/奖励颜色和暂停/继续。不增加强制教程流程。
- 结算反馈只展示已有分数、金币、用时、关卡等本局状态；不重复结算奖励或更改存档结构。
- 验收：帮助不会启动/推进/覆盖当前 run；每条说明和实际事件绑定一致；减动态效果下不增加闪白/震屏；仍使用规范色彩与字体，操作区焦点态可见。
- 实施：补充菜单技能/暂停说明、暂停页技能与危险/奖励提示；读屏状态摘要本局分数、新纪录/最佳分、金币、时间和到达关卡。`end()` 增加 `play` 状态保护，重复调用不会重复计数。
- 验收：文案与现有动作匹配、保留视觉令牌，回归套件 29/29 通过。

## 完整自动输入矩阵

| 玩家动作 | 预期 Canvas/传统输入 | 预期语义 DOM | 状态/数据断言 |
|---|---|---|---|
| 开局/每日 | 点菜单按钮/Enter/2 | Start / Daily 按钮 | 进入 play，普通/每日 seed 行为不变 |
| 购买 | 点商店项目 | Purchase upgrade/skill | 余额减正确价格且购买等级/拥有态仅变化一次 |
| 翻页/查看关卡 | Canvas 页按钮 | 上/下一页、上/下关卡 | 索引环绕范围有效，内容正确 |
| 操控/技能 | 左右键/拖动/1–4 | 技能 1–4 | 仅购买且冷却完成的技能生效 |
| 暂停/恢复 | P/Esc/Canvas | Pause / Resume | 输入清理且状态唯一切换 |
| Boss 后继续 | Canvas 继续 | Continue run | 继续同一局，不重复奖励 |
| 结束/重试/返回 | 空格/按钮 | Retry/Menu | 最佳分与奖励仍只结算一次 |
| 存档刷新 | save core fixture | 导出 | 有效值 round-trip，坏/未来原文不覆盖 |
