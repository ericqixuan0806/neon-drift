## 首帧绘制回归修复（2026-10-09）

- 反馈现象：页面只看到深色背景板。
- 复现证据：执行真实游戏代码的首个动画帧时抛出 `ReferenceError: n is not defined`。背景先画出，随后 `draw()` 在星点/速度条绘制处中断。
- 根因与修复：减少动态效果改动将 `n` 放进 `bgd()` 局部作用域，但 `draw()` 仍复用该变量。现已让 `draw()` 自行取得动效时钟，并通过 `motion()` 应用系统偏好。
